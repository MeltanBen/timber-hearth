# Timber Hearth

一个 Minecraft Fabric 模组，添加了棉花糖相关的物品、方块和生物。

## 环境要求

- Minecraft 1.21.1（暂时只有这个版本）
- Fabric Loader 0.19.5+
- Fabric API 0.116.17+1.21.1
- Java 21

## 添加的内容

### 物品
- **棉花糖**：可以吃。四个糖围成一个正方形合成
- **棉花糖发射器**：右键发射棉花糖，有击退效果并且掉落棉花糖。棉花糖罐外围一圈棉花糖合成
- **哈斯鱼桶**：桶装哈斯鱼

### 方块
- **棉花糖罐**：outerwilds严选棉花糖（）。棉花糖外围一圈铁锭合成

### 生物
- **哈斯鱼（Hearthian）**：会自然生成在繁茂洞穴，吃棉花糖，暂时不会繁殖，可以用水桶装

## 安装

1. 下载mc1.21.1
2. 下载fabric和对应API
3. 把模组 jar 放进 `.minecraft/mods/` 文件夹

## 构建

```bash
./gradlew build
